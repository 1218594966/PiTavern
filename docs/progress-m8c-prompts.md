# M8c 提示词职责重构（路由 = 选角导演 / 演员 = 演绎者）

> 用户指正：两阶段提示词写反了职责 —— 路由不是关键词裁决器，演员不是裸拼装文本。
> - 路由：看清剧情发展 → 挑出本回合该上场的人/被触动的旧事/该去的场景（叙事编排）
> - 演员：拿到挑好的卡 + 固定设定 → 以被点名的角色身份做演绎

## 路由提示词重构（src/stages/pre-router.ts buildRouterContext）
- **输入**：`RouterInput.recentLines` —— pipeline 在阶段 1 前取最近剧情
  （排除刚 push 的本回合玩家输入，只留上一回合及更早，旧→新）。
- **systemPrompt 重写**：从「挑卡裁决器（关键词规则触发）」改为
  「**选角导演（叙事编排）**」：顺剧情自然发展判断谁在场/谁开口/什么伏笔被触动；
  原则写清：默认保留在场角色、只挑真正触碰的旧事/物件、真移动才换场景。
- **user 内容**：
  - 目录带叙事注解：人物标注「已在场 ← / 未在场 ← 可被召唤或闯入」；
    旧事标注「提起 X 时会想起」；物件标注位置；
  - 新增「【最近剧情】」段（上一回合实际发生的事）；
  - 玩家现在的行动 → 输出抽卡清单 JSON。

## 演员提示词重构（src/pipeline.ts actorContext）
- 新增**演绎框架段**（置于组装设定之前）：
  「你是「{speaker 角色名}」，身处上文场景，只以该角色身份说话行动。
   演绎要求：贴合设定（性格/说话风格/关系经历）；顺着对话自然回应；一轮只开口一次；
   不替其它角色发言；直接输出台词，不要旁白/引号；字数自然。」
- systemPrompt = `演绎框架 + 「===== 以下为本回合的完整设定 =====」 + assembled.prompt`。
- 角色名从 `decision.speakerCharacterId` → index.characters 查得。
