# M9c UI 精简与语义修正

> 用户指正一批 UI 问题，逐项落地。

## 1. 「↻ 新楼层」→「↻ 重新生成」
原词误导（以为是开新楼层）；实际是 regenerate（删对重跑 + 旧楼层迁移）。
操作条改为「↻ 重新生成」，语义即重 roll 本段回复。

## 2. 删除「上下文水位」功能
判断：记忆分层（旧层摘要 + 缓冲全文）+ 流水线抽卡（路由决定贴哪些卡）已经决定 token，
水位条没有提供额外价值。整个卡（ctx-bar/ctx-total/图例/警告）删除；
renderContextMeter 函数与其调用、CSS 一并清理。
真正的「上下文显示」由下面的模型收发面板承担（③ 演员收到的完整输入 = 系统提示词 + 抽出的卡 + 窗口）。

## 3. 「🗂 画廊」按钮删除
世界库卡片点击 = 切世界 + 打开该仓库分组浏览（画廊抽屉），点卡即可看分类；
卡片右上 🗂 小按钮也已存在，故侧栏「画廊」按钮冗余 → 移除（openGallery 绑定保留给卡片）。

## 4. 导入/导出从世界库移到 ⚙ 设置弹层
侧栏世界库只剩：仓库卡列表 + 状态行 + 拆卡动画区（导入反馈）；
「🃏 导入 / 导出游戏卡」区放设置弹层内（📥 导入 JSON/PNG / 📤 导出当前世界角色卡 + 粘贴区）。

## 5. 删除「示例世界」按钮
demo_world 本就在世界库里（演示旅馆），按钮多余 → 移除。

## 6. 模型收发面板常驻 + 独立成卡
原「🔍 模型收发」从四阶段卡内移出，独立为右侧一张常驻卡
「🎭 本回合模型上下文（路由抽卡 / 演员演绎的完整收发）」：
- 默认可见（不再发送后才出现）：空态显示「等待回合…发一句话后这里实时展示…」；
- 回合结束清数据不隐藏；路由/演员数据到达即填充（块级折叠、各层 Request/Response 全量）。

## 清理
- m-mode 残留赋值、renderContextMeter、ctx CSS、world-gallery/world-demo 绑定全删；
- JS 空 id 引用核查：仅剩已删世界状态面板的 4 个元素（引用均带空守卫，安全）。

## 验证
- JS 语法 / CSS 括号平衡通过；服务 http://127.0.0.1:3100 已更新。
