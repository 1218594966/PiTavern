## B1 — Redis 滑动历史同回合乱序（已修复）

- **现象**：世界级/会话级历史用 ZSET(score=turn, member=整条 JSON)。同一回合写入两条同分记录（玩家输入 + NPC 回话），Redis 对同分成员按 member 字典序排列，`zrevrange+reverse` 后同回合两条消息顺序颠倒（`"speaker":"NPC"` 字典序小于 `"speaker":"user"`）。
- **修复**（src/db/store.ts）：
  - 历史从 ZSET 改为 **LIST（RPUSH 右进 / LTRIM 左裁）**，天然保插入序。
  - `pushHistory` / `pushChatMessage` 用单条 multi（RPUSH+LTRIM）保持原子性。
  - `recentHistory` / `recentChatMessages` 用 `LRANGE -n -1` 一次取回（旧→新）。
  - `allChatMessages` 用 `LRANGE 0 -1`。
- **回归测试**：`test/store.test.ts` 新增「同回合两条消息保持写入先后」，mock Redis 支持 rpush/ltrim/lrange；同时更新旧 ZSET mock 为新 LIST mock。
- 键空间注释同步更新。

## B2 — 回合号语义：前台推进 + 结算解耦（已修复）

- **现象**：回合号只在后台结算 `applyEvalResult` 里 `turn += 1`。快速连发时第 2 回合可能读到结算前的 turn → 两回合 turn 撞车；turn 语义依赖结算成功。
- **修复**：
  - pipeline.ts：回合开始取 `currentTurn = state.turn`；玩家输入与 NPC 回话都用 `currentTurn` 写历史；回合末 **前台** 把 `state.turn = nextTurn` 并同步落盘（会话→chat.state，无会话→world state），之后才触发后台结算。
  - post-evaluator.ts `applyEvalResult`：**不再**推进回合号 / 全量写 state；仅当发生物品转移（背包变化）才同步 state 里的 `playerInventory` 并落盘（该路径经按会话串行化的 runner，无并发写冲突）。
- **验证**：两回合快速连发脚本 → 历史 turn 序列 `user:1|NPC:1|user:2|NPC:2`，最终 `state.turn=3`（PASS）。
- 测试：pipeline 全链路测试仍断言最终 `state.turn=2`（一回合后），语义保持。

## B3 — Web 模型热切换与"真实 + faux 混搭"（已修复）

- **现象**：
  1. `server.ts isAllFaux()` 只查 env Key；网页填的运行时 Key 只在内存（setRuntimeKey），无 .env Key 时网页热切换真实模型，`stageModels` 换成真实模型但 `models` 集合仍是 faux 集合 → 调不通。
  2. 代码在「全真实集合」与「faux 集合」间二选一，无法支持「某阶段真实、其它阶段 faux」的混合配置。
  3. `getStageModel` 对"配了 Key 但目录未 refresh"静默回退 faux → 用户以为在用真实模型实际被降级。
- **修复**：
  - provider-registry.ts：把三个 faux provider 注册进 **共享 Models 集合**（与真实 provider 混搭）；新增 `getFauxRegistration`；`buildModels()` 统一构建。
  - models.ts：`getFauxModelsCollection()` 退化为 `getModels()`（单一集合）；新增 `stageUsesRealModel(stage)`、`providerHasKey`、`fauxStageModel`、`resolveStageModelAsync`（目录缺失时 refresh 一次再查）；`getStageModel` 在"有 Key 但模型不在目录"时抛 `MODEL_UNAVAILABLE`（不静默回退 faux）。
  - server.ts：删除 `isAllFaux()`；启动用 `resolveStageModelAsync(...).then(m => m ?? getStageModel(...))`；hello 携带逐阶段 `stages` 布尔；`provider_set` 走 `resolveStageModelAsync`（找不到则报错且配置不生效）；`models` 常量为共享集合，热切换只更新 `stageModels`。
  - demo.ts：配 Key 时先 `ensureCustomProvider + refresh` 再解析；无 Key 三阶段落 faux。
- **验证**：
  - 无 .env Key（临时移走 .env）→ demo 打印 `faux-router/route-3b` 等三阶段，faux 全链路跑通并结算。
  - 有 .env Key → demo 用 commandcode 真实模型完整跑通（router 真实裁决、actor 真实流式回话、结算真实写回）。
  - web server 启动 + /health + index 200 冒烟通过。
- 注：faux 注册时补回 `tokensPerSecond`（80/120/60），保持流式打字节奏与既有测试时序一致。
